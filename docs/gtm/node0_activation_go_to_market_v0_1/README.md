# BIZRA Node0 Activation Go-to-Market Kit v0.1

**Status:** Phase 1 handover kit draft  
**Scope:** Private pilot, operator readiness, GTM, business model, and investor/operator handover.  
**Truth discipline:** Do not claim production federation until a second physical node completes an independently verified signed-receipt exchange.

## Executive Position

Node0 is ready as a single-node sovereign runtime through Tier C. It is not yet ready for external-user production, paid ads, or Genesis-100 scale claims. The next honest milestone is a private pilot with a small number of ready user devices, beginning with a two-node URP handshake.

Canonical sentence:

> Node0 proves the seed can live alone; URP lets seeds connect; SAT lets the forest coordinate; autopoiesis lets the forest improve without breaking node sovereignty.

## Decision Dashboard

| Area | Current call | Meaning |
|---|---|---|
| Node0 Tier A-C | GO | Single-node identity, receipts, and visible surface are operational enough for internal activation. |
| Tier D external use | NO-GO | Missing onboarding, hardware profile, privacy/claim cleanup, kill-switch, and ingestion-gate spec. |
| Multi-node URP | PLANNED | Heartbeat/prototype exists; production bootnode and second-node handshake are not proven yet. |
| Local pilot handshake artifact | MEASURED_LOCAL_ARTIFACT | Node0 can generate and verify a signed private-pilot handshake JSON artifact. |
| Organic launch | Conditional GO | Safe after visual QA, Arabic review, operator sign-off, and website claim cleanup. |
| Paid ads | NO-GO | Blocked by claim discipline, landing page, creative QA, policy setup, and kill-switch. |

## Phase Order

1. Close documentation and operator readiness.
2. Run private pilot readiness checks on Node0 and one candidate user device.
3. Implement or expose the minimal signed-receipt URP handshake.
4. Produce a pilot evidence pack from real device results.
5. Use measured evidence to update investor, website, launch, and paid-ad materials.
