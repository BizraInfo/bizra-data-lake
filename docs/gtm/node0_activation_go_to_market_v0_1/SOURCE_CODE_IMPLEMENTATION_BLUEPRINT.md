# Source-Code Implementation Blueprint

## Purpose

This blueprint maps the private-pilot source path for connecting ready user devices without claiming production federation. The first implementation milestone is a signed handshake artifact that can be generated by Node0, sent to a trusted user node, and verified independently.

## Current Code Surfaces

| Surface | Role | Current use |
|---|---|---|
| `scripts/node0_standalone.py` | Operator entrypoint | Pilot doctor, signed handshake artifact, and artifact verification. |
| `core/pci/crypto.py` | Cryptographic primitives | RFC-style canonical JSON, BLAKE3 domain digest, Ed25519 sign/verify. |
| `core/genesis/urp.py` | URP pledge | Single-node resource pledge and signature verification. |
| `bizra-omega/bizra-mission/src/receipt.rs` | Mission receipt canon | BLAKE3-chained, Ed25519-signed mission receipts. |
| `bizra-omega/bizra-resourcepool/src/lib.rs` | Resource pool substrate | Node registration and resource-pool types; not a production bootnode yet. |
| `bizra-omega/bizra-resourcepool/src/main.rs` | Resource pool CLI | Genesis/status commands only; join command remains advertised but not implemented. |

## Implemented Pilot Commands

### `pilot-doctor`

Read-only readiness report for the private pilot.

```bash
python scripts/node0_standalone.py pilot-doctor
```

It checks:

- GTM/private-pilot documents exist.
- Node0 lifecycle has identity, URP, and MVSA gates.
- Kill-switch documentation exists.

### `pilot-handshake`

Creates a local signed handshake JSON artifact. This is not network discovery or consensus.

```bash
python scripts/node0_standalone.py pilot-handshake \
  --peer-node-id node1 \
  --peer-public-key <64-hex-ed25519-public-key> \
  --peer-address 127.0.0.1:9749 \
  --operator MoMo \
  --out sovereign_state/private_pilot/handshakes/node1.json
```

The artifact includes:

- Local node id.
- Peer node id.
- Peer public key.
- Peer address.
- Operator label.
- Nonce.
- Optional previous receipt hash.
- Explicit non-claims: not production federation, not open discovery, not Genesis 100.
- Payload digest.
- Signature.
- Receipt hash.

### `pilot-verify`

Verifies a handshake artifact fail-closed.

```bash
python scripts/node0_standalone.py pilot-verify sovereign_state/private_pilot/handshakes/node1.json
```

It rejects:

- Missing payload.
- Payload digest mismatch.
- Invalid signature.
- Receipt hash mismatch.

## First Two-Device Pilot Flow

1. Run `pilot-doctor` on Node0.
2. Run local readiness checks on the user device.
3. Generate or collect the user device public key.
4. Run `pilot-handshake` on Node0 for the user device.
5. Send the JSON artifact to the user device.
6. Run equivalent verification on the user device using the artifact's `signer_public_key`.
7. Have the user device produce its own signed artifact for Node0.
8. Run `pilot-verify` on Node0 against the user artifact.
9. Archive both artifacts in the pilot evidence pack.

## Why This Is the Right First Cut

This path proves the minimum cross-node truth boundary without pretending the production URP bootnode exists. It is intentionally artifact-first:

- It exercises canonical serialization.
- It uses Ed25519 signatures.
- It produces portable JSON proof.
- It can be tested locally.
- It keeps the claim label honest: `MEASURED_LOCAL_ARTIFACT`, not production federation.

## Remaining Source Work Before Real Multi-Node Production

- Implement a real `resourcepool-node join` command or dedicated bootnode service.
- Add peer transport and retry semantics.
- Bind private-pilot artifacts to mission receipts or resource-pool registration receipts.
- Add replay protection beyond nonce and optional previous receipt hash.
- Add persistent peer registry and revocation list.
- Add networked happy-path and invalid-peer integration tests.
- Add release SBOM and continuous secret-scanner gates.

## Acceptance Criteria for Phase 2

Phase 2 is complete when:

- The operator has a documented code map.
- Node0 can produce a signed pilot handshake artifact.
- The artifact verifier rejects tampering.
- Tests cover signing and tamper rejection.
- Public docs continue to label production federation as planned, not measured.
