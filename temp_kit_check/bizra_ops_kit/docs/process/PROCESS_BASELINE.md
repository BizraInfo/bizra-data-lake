# Process Baseline (v0.1)

This kit supports a lightweight process loop:

1) **Plan**: define goal + acceptance criteria
2) **Execute (PAT)**: run work scripts
3) **Validate (SAT)**: run tests/scans
4) **Record**: store receipts + outputs under evidence
5) **Ship**: tag/release/baseline
6) **Review**: retro + improvements

Keep it small: evidence beats narratives.
