# Giants: The Shoulders BIZRA Stands On

BIZRA measures giants by mission impact, not brand recognition (ADR-001).

---

## The Giants

### George Necula — Proof-Carrying Code (1997)
**Impact on BIZRA:** The foundational idea that a program can carry its own proof of safety. BIZRA's receipt chain is PCC applied to agent actions: every mission result carries a cryptographic receipt proving constitutional compliance.
**Component:** Receipt chain, Proof Engine

### Jack Dennis & Earl Van Horn — Object Capabilities (1966)
**Impact on BIZRA:** The principle that authority should be unforgeable and transferable only through explicit channels. BIZRA's membrane is a capability boundary: crossing requires constitutional authorization.
**Component:** Constitutional Membrane

### Satoshi Nakamoto — Hash-Chained Ledgers (2008)
**Impact on BIZRA:** Append-only, hash-linked data structures for trustless verification. BIZRA uses BLAKE3 chains for receipt integrity, replacing proof-of-work with Proof of Impact.
**Component:** BLAKE3 receipt chains, SEED ledger

### Haskell Curry & William Howard — Types as Proofs (1934/1969)
**Impact on BIZRA:** The correspondence between type systems and logical proofs. BIZRA's Rust newtypes enforce constitutional invariants at compile time — an IhsanScore below 0.95 is not a runtime error, it's a type error.
**Component:** Constitutional type constraints

### Aleksandr Lyapunov — Stability Theory (1892)
**Impact on BIZRA:** Mathematical framework for proving system stability without solving the full dynamics. BIZRA's heartbeat daemon and convergence metrics are Lyapunov-inspired: prove the system stays bounded without predicting every state.
**Component:** Heartbeat stability, convergence analysis

### Humberto Maturana & Francisco Varela — Autopoiesis (1972)
**Impact on BIZRA:** The theory of self-producing, self-maintaining systems. BIZRA's N=1 flywheel is a computational autopoietic loop: the organism maintains itself through its own receipt-verified operation.
**Component:** Self-improving flywheel, Cognitive Materialization 6/6

### The Babylonian Scribes — Regular Numbers (~2000 BCE)
**Impact on BIZRA:** 5-smooth numbers (factors of 2, 3, 5 only) have exact finite representation in base-60. BIZRA's Sippar crate uses this for zero-drift economic computation, making extraction through rounding errors structurally impossible.
**Component:** bizra-sippar crate, RIBA_ZERO arithmetic layer

### Islamic Hadith Scholars — Isnad Science (~8th century CE)
**Impact on BIZRA:** The systematic evaluation of narrator chains to determine report authenticity. A single unreliable narrator invalidates the entire chain. BIZRA's IRP trust model applies this: Trust(claim) = min(T(narrators)).
**Component:** Isnad Risk Propagation, House of Wisdom governance

### Anthropic — Constitutional AI (2022)
**Impact on BIZRA:** Training models to follow written principles through self-improvement. BIZRA extends this from model-level alignment to system-level topology: the constitution governs the network boundary, not just the model output.
**Component:** Constitutional Spine, axiomatic filtering

### Kurt Godel — Incompleteness Theorems (1931)
**Impact on BIZRA:** Any sufficiently powerful system cannot prove its own consistency. BIZRA's Frozen Agent Principle breaks the self-referential trap by freezing ethical evaluation on external axioms. The system improves capabilities without modifying its own evaluation criteria.
**Component:** P5 Ethicist (frozen), S2 Oracle (frozen)

## The Pattern

BIZRA did not invent proof-carrying execution, hash chains, type-safe constraints, stability analysis, autopoiesis, exact arithmetic, narrator-chain trust, constitutional alignment, or Godelian escape hatches. It synthesized them into one constitutional whole. That synthesis — applying each giant's insight to the specific problem of sovereign personal AI — is the contribution.

*Standing on the shoulders of giants is more impressive, not less.*
