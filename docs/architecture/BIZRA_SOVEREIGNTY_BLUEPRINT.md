# IMPLEMENTATION SEQUENCE

## Week 1-2: Stand Alone Validation

```bash
# Day 1-3: PAT Validation
pwsh ./scripts/genesis_ignite_all.ps1  # Ensure stack operational
python agent_runner.py --list          # Verify all 7 PAT agents
python agent_runner.py --agent MasterReasoner --message "Test sovereignty"

# Day 4-5: SAT Activation
curl http://localhost:8080/api/sat/agents
curl http://localhost:8080/api/sat/resources

# Day 6-7: Offline Test
# Disconnect network, run full PAT/SAT cycle
```

## Week 3-4: Data Refinery MVP

```bash
# Run enhanced refinery
python bizra_refinery.py --scan ~/Gold_Mine --output ./refined_data/

# Verify embeddings
python -c "from chromadb import Client; c=Client(); print(c.list_collections())"

# Test RAG retrieval
python agent_runner.py --agent MasterReasoner --message "What is BIZRA?" --rag
```

## Week 5-8: Instruction Synthesis

```bash
# Generate QA pairs
python tools/generate_instruction_dataset.py \
  --input ./refined_data/ \
  --output ./datasets/bizra_instruct_v1.jsonl \
  --format alpaca

# Validate quality
python tools/validate_dataset.py --input ./datasets/bizra_instruct_v1.jsonl
```

## Week 9-12: First BIZRA Model

```bash
# Setup Unsloth
pip install unsloth

# Train LoRA adapter
python train_bizra_reasoner.py \
  --base deepseek-r1:7b \
  --dataset ./datasets/bizra_instruct_v1.jsonl \
  --output ./models/bizra-reasoner-7b-v0.1

# Convert to GGUF
python convert_to_gguf.py --input ./models/bizra-reasoner-7b-v0.1

# Deploy to Ollama
ollama create bizra-reasoner:7b -f ./models/Modelfile
```
