## Evidence Receipt

Each receipt is a single JSON file in `.proof-forge/receipts/`.

```json
{
  "schema_version": "1.0.0",
  "receipt_id": "receipt-YYYY-MM-DD_HHMMSS",
  "timestamp": "ISO-8601 UTC",
  "description": "Human-readable description of what was built/changed",
  "chain_position": 1,

  "hashes": {
    "evidence_hash": "SHA-256 of (artifacts + verification + description)",
    "previous_hash": "chain_hash of previous receipt (or 64 zeros for genesis)",
    "chain_hash": "SHA-256 of (evidence_hash + previous_hash + timestamp)"
  },

  "confidence": {
    "level": 1,
    "label": "Logged | Attested | Solid | Strong | Ironclad",
    "criteria": "Human-readable explanation of why this level"
  },

  "artifacts": {
    "count": 42,
    "summary": {
      "code": 20,
      "test": 8,
      "config": 5,
      "doc": 7,
      "data": 2
    },
    "details": [
      {
        "path": "src/main.rs",
        "size_bytes": 1234,
        "sha256": "abc123...",
        "modified": "ISO-8601",
        "type": "code"
      }
    ]
  },

  "verification": {
    "verification_id": "verify-YYYYMMDD-HHMMSS",
    "timestamp": "ISO-8601",
    "ecosystems": ["rust", "node"],
    "checks": [
      {
        "type": "test_suite | benchmark | schema_validation | static_analysis | build_check",
        "command": "cargo test",
        "exit_code": 0,
        "passed": true,
        "duration_ms": 1234,
        "summary": "test result: ok. 42 passed; 0 failed",
        "output_excerpt": "first 2000 chars..."
      }
    ],
    "checks_run": 3,
    "checks_passed": 3,
    "checks_failed": 0,
    "overall_pass": true,
    "manual_attestation": null
  }
}
```

### Hash Computation Rules

**evidence_hash**: Canonical JSON serialization of `{artifacts, verification, description}`,
sorted by keys, minimal separators, then SHA-256.

**chain_hash**: `SHA-256(evidence_hash + previous_hash + timestamp)` as a concatenated string.

**Genesis**: The first receipt uses `previous_hash = "0000...0000"` (64 zeros).

## Evidence Index

Single file at `.proof-forge/EVIDENCE_INDEX.json`. Append-only.

```json
{
  "schema_version": "1.0.0",
  "project": "project-directory-name",
  "genesis_timestamp": "ISO-8601 of first receipt",
  "chain_length": 7,
  "latest_hash": "chain_hash of most recent receipt",
  "latest_receipt": "2026-02-07_001823.json",
  "receipts": [
    {
      "position": 1,
      "filename": "2026-02-01_120000.json",
      "timestamp": "ISO-8601",
      "chain_hash": "abc123...",
      "confidence_level": 3,
      "confidence_label": "Solid",
      "description": "First 200 chars of description"
    }
  ]
}
```

## Verification Report

Produced by `verify_artifacts.py`, consumed by `forge_evidence.py`.

```json
{
  "verification_id": "verify-1738886303",
  "timestamp": "ISO-8601",
  "ecosystems": ["rust"],
  "checks": [
    {
      "type": "test_suite",
      "command": "cargo test",
      "exit_code": 0,
      "passed": true,
      "duration_ms": 4521,
      "summary": "test result: ok. 127 passed; 0 failed",
      "output_excerpt": "..."
    }
  ],
  "checks_run": 3,
  "checks_passed": 3,
  "checks_failed": 0,
  "overall_pass": true,
  "manual_attestation": null
}
```

### Check Types

| Type | Description |
|------|-------------|
| `test_suite` | Unit/integration test execution |
| `benchmark` | Performance benchmark execution |
| `static_analysis` | Linting, type checking, clippy |
| `schema_validation` | JSON schema, XSD, protobuf validation |
| `build_check` | Compilation / build verification |

## Proof Summary Structure

Markdown file generated by `proof_summary.py`. Structure:

1. **Title + Receipt Number**
2. **Description + Timestamp** (blockquote)
3. **Confidence Level** (visual bar + label)
4. **Verification Results** (table of checks)
5. **Artifacts** (file count + type breakdown)
6. **Evidence Chain** (hashes + chain position)
7. **Full Hash Values** (collapsible, for independent verification)
8. **Footer** (generator attribution)

---

## Confidence Level Computation

| Level | Label | Rule |
|-------|-------|------|
| 5 | Ironclad | `test_suite` passed AND 3+ other check types passed |
| 4 | Strong | `test_suite` passed AND 1+ other check type passed |
| 3 | Solid | `test_suite` passed OR (`static_analysis` + 1 other) |
| 2 | Attested | Any check passed OR manual attestation provided |
| 1 | Logged | No checks passed, evidence collected only |

The confidence level is deterministic — same inputs always produce the same level.
