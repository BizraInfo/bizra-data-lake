# 🤝 BIZRA Community Guidelines

**Welcome to the BIZRA community!** We're building the world's first truly sovereign AI infrastructure, and we're doing it together.

---

## 🌟 Our Values

### 1. **İhsān** (Excellence)
We strive for 95%+ quality in everything. This applies to code, communication, and community interactions.

### 2. **Transparency**
- Development happens in public
- Roadmap is openly shared
- Decisions are explained
- Failures are acknowledged

### 3. **Sovereignty**
- Every human is a node
- Every node is equal
- No centralized control
- Your data, your rules

### 4. **Kindness**
- Assume good intentions
- Help newcomers
- Celebrate contributions
- Learn from mistakes

## 🎯 How to Contribute

### As a User

**1. Use BIZRA Daily**
The best contribution is dogfooding. Use it, break it, report issues.

**2. Share Feedback**
- What delights you?
- What frustrates you?
- What's missing?

**3. Spread the Word**
- Tweet about your experience
- Write blog posts
- Make tutorial videos

### As a Developer

**1. Read [CONTRIBUTING.md](CONTRIBUTING.md)**
Understand our Git workflow, coding standards, and review process.

**2. Start Small**
- Fix typos in documentation
- Improve error messages
- Add unit tests
- Write examples

**3. Claim an Issue**
Check [good first issue](https://github.com/BizraInfo/bizra-data-lake/labels/good%20first%20issue) label.

**4. Propose Features**
Open a GitHub Discussion before implementing large features.

### As a Writer

**1. Write Tutorials**
- "Getting Started with BIZRA"
- "Building Your First Agent"
- "Understanding Proof-of-Impact"

**2. Create Documentation**
- API references
- Architecture diagrams
- Case studies

**3. Translate**
- Help make BIZRA accessible globally
- Arabic, French, Spanish, Chinese, etc.

## 📜 Code of Conduct

### ✅ We Encourage

- **Asking questions:** No question is stupid
- **Sharing failures:** We learn from mistakes
- **Proposing ideas:** Wild ideas welcome
- **Constructive criticism:** Help us improve
- **Celebrating wins:** Success is shared

### ❌ We Don't Tolerate

- **Harassment:** Of any kind, toward anyone
- **Discrimination:** Based on race, gender, religion, etc.
- **Spam:** Promotional content without value
- **Trolling:** Bad faith arguments, derailing
- **Doxing:** Sharing private information

**Enforcement:** Violations result in warnings, temp bans, or permanent bans depending on severity.
