# Investor and Operator Handover

## Executive Summary

BIZRA is a proof-native sovereign AI system with a working single-node foundation and a strong brand canon. The immediate value is not a claimed global network. The immediate value is Node0: a local sovereign runtime that can move toward multi-node verification through measured private pilots.

## What Is Proven

- Node0 has documented single-node readiness through Tier A-C.
- Mission lifecycle and receipt concepts are implemented in the Rust workspace.
- Brand identity and claim-safe launch copy exist.
- Audit artifacts identify current blockers clearly.
- URP is canonically Universal Resource Pool.
- Node0 can now generate and verify a signed local private-pilot handshake artifact. Evidence is registered in `PILOT_EVIDENCE_REGISTER.md`.

## What Is Not Yet Proven

- Production URP bootnode.
- Open multi-node discovery.
- Second physical node joining and verifying receipt exchange.
- SAT-5 network coordination.
- Genesis-100 scale.
- Paid ad compliance.

## What We Are Asking Stakeholders to Believe

Only this:

> The single-node foundation is strong enough to justify a controlled private pilot whose purpose is to generate the missing multi-node evidence.

## Operator Priorities

1. Close runbooks and hardware profile.
2. Select trusted pilot devices.
3. Run first two-node signed receipt exchange.
4. Preserve evidence.
5. Update public and investor claims only after evidence exists.

## Investor Priorities

1. Understand the wedge: proof-bearing sovereign nodes.
2. Evaluate founder velocity and proof discipline.
3. Review pilot evidence rather than hype claims.
4. Support strategic partnerships where local-first AI and governance matter.
