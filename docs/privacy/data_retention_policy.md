# Data Retention & Privacy (Template)

## Data inventory and classification
- Public / Internal / Confidential / Restricted
- Identify PII fields and sensitive logs/prompts

## Retention defaults (example - adjust)
- Auth/security logs: 30-90 days
- Request metadata (non-PII): 13 months
- Prompts/outputs: opt-in only; default minimal retention

## User rights (if applicable)
- Export: portable format + receipt
- Erase: logical + physical deletion where required, plus cache purge
- Audit: record who/when/why for access to sensitive data
